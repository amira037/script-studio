  라우팅 우선순위 요약 (handleScriptPrompt 내부 순서):
  1. 인물명 + 분석 키워드 → analyzeCharacter

  3. 참조 + 새씬 + selectedIds≥2 → handleRefSceneCreate                         
  4. 합치기 키워드 → handleSceneMerge                                           
  5. 각종 명확한 키워드 직접 매칭 (제목/잠금/복제/요약/추가 등)                 
  6. 분석 키워드 → haikusRoute → dispatchCmd                                    
  7. 대안교체/특성/diff 키워드 → Haiku 의도 판단                                
  8. 브레인스토밍 판단 → Haiku → showBrainstormSuggestion 또는 편집 계속
