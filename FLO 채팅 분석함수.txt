  각 분석 함수 상세
                   
  checkConflictWithPrompt (L16894)
                                                                                
  - 입력: 씬 ≥ 2개, draft 제외                                                  
  - 처리: Haiku로 씬별 갈등 강도(1~5) + 유형(인물vs인물 등) → 별도 호출로 advice
   + summary                                                                    
  - 출력: 갈등 그래프 + <summary>, <detail>, <advice> → openConflictModal
  - 후처리: S.cur.conflictData에 캐시 저장                                      
                                                                                
  handleFlowAnalysisInChat(text, mode) (L14356)                                 
                                                                                
  mode 3종:                                                                     
                  
  ┌─────────┬────────────────────────────────┬──────────────────────────────┐   
  │  mode   │           분석 내용            │             출력             │
  ├─────────┼────────────────────────────────┼──────────────────────────────┤
  │ flow    │ 씬 연결이 매끄럽지 않은 부분   │ <issue sc="N"> 태그 +        │
  │         │                                │ 방안1/2/3                    │
  ├─────────┼────────────────────────────────┼──────────────────────────────┤   
  │ emotion │ 감정/심리 흐름 부자연스러운    │ 동일                         │   
  │         │ 변화                           │                              │   
  ├─────────┼────────────────────────────────┼──────────────────────────────┤   
  │ setting │ 인물 설정·사실 관계 모순·충돌  │ 동일                         │
  └─────────┴────────────────────────────────┴──────────────────────────────┘

  - 출력: 방안별 [방안N으로 개선하기] 버튼 + [플로 종합 제안] 버튼 (방안 ≥ 2개일
   때)
  - 후처리: 개선 제안 있으면 setPendingReminder 등록                            
                                                                                
  checkConsistencyWithPrompt (L14490)
                                                                                
  - 처리: 전체 씬 대본 + 캐릭터 설정 → <issues>[{"level","scene","message"}]    
  - 출력: showCheckPanel (error/warn/ok 이슈 목록)
                                                                                
  handleSceneConnection (L13002)                                                
                                                                                
  - 처리: SC번호 명시 or selectedIds or 전체 → 씬 앞뒤 흐름 분석                
    - 단일 씬: 앞뒤 씬 포함해서 분석
    - 복수 씬: 연결 구간 분석                                                   
    - 전체: 씬 목록 기반 분석                                                   
  - 출력: showCheckPanel or showFlowCheckPanel                                  
                                                                                
  reorderByConflict (L15664)                                                    
                                                                                
  - 전제: S.cur.conflictData 존재해야 함 (없으면 갈등 분석 먼저 제안)           
  - 처리: 갈등 강도 데이터 → Haiku가 최적 순서 계산 → <reorderscenes> 태그
  - 출력: [↕ 순서 재배치 미리보기] 버튼 → showReorderPreviewModal               
                                                                                
  handleCharDialogueAnalysis (L15926)                                           
                                                                                
  - 전제: 텍스트에 등록된 인물명 포함                                           
  - 처리: 해당 인물 전체 대사 수집 → Haiku가 극적 중요 대사 3~5개 선별 → 특성
  추출                                                                          
  - 출력: 선별 대사 목록 + 분석 설명 + [keyline 지정] 버튼
  - 참고: 채팅에서는 라인에디터로 위임함 (dialogue_analysis cmd)
